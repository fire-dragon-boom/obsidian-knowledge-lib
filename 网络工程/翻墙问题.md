## 与tailscale冲突配置
```yaml
# Profile Enhancement Merge Template for Clash Verge

# 1. 保留原本的节点记忆功能
profile:
  store-selected: true

# 2. 强制将 TUN 排除规则合并到所有配置文件中
prepend-tun:
  enable: true
  stack: mixed
  auto-route: true
  auto-detect-interface: true
  exclude-interface:
    - Tailscale
    - Tailscale Tunnel
  route-exclude-address:
    - 100.64.0.0/10

# 3. 强制让 Tailscale 软件进程直连
prepend-rules:
  - PROCESS-NAME,tailscale.exe,DIRECT
  - PROCESS-NAME,tailscaled.exe,DIRECT
    
```
