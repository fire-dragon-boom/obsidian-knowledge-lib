# tailscale
## 安装
### docker compose
```yml
services:
  tailscale:
    image: tailscale/tailscale:latest
    container_name: tailscale
    network_mode: host                # 使用 host 模式共享 WSL 网络
    privileged: true                  # 给予特权以创建 TUN 虚拟网卡
    volumes:
      - ./tailscale_state:/var/lib/tailscale  # 持久化保存密钥和登录状态
      - /dev/net/tun:/dev/net/tun             # 映射网卡驱动核心
    environment:
	  - TS_HOSTNAME=wsl/debian  #设置ts主机名
      - TS_USERSPACE=false
      - TS_STATE_DIR=/var/lib/tailscale # 持久化登录状态，在挂载卷里可以看到state文件
      - TS_EXTRA_ARGS=--advertise-exit-node  # 设置作为出口节点
    restart: unless-stopped
```

## 配置
### 登录
执行命令，复制登录链接浏览器登录，查看控制台链接状态
```bash
docker exec -it tailscale tailscale up --reset
```

### 作为exit node代理（vpn）
1. 开启本地的ip转发
	```bash
	# 配置转发
	sudo tee /etc/sysctl.d/99-tailscale.conf <<'EOF' 
	net.ipv4.ip_forward = 1 
	net.ipv6.conf.all.forwarding = 1 
	EOF
	
	# 生效
	sudo sysctl --system
	
	# 查看
	sysctl net.ipv4.ip_forward sysctl net.ipv6.conf.all.forwarding
	```
2. 设置ts作为exitnode
	docker添加环境变量`TS_EXTRA_ARGS=--advertise-exit-node` 
	之后在控制台同意即可

### 子网路由
1. 在设备上添加子网，控制台同意，就可以访问设备所在子网的其他设备了
