# ollama

## 常用命令
```bash
# 查看版本
ollama --version

# 下载默认版本的模型（通常是最新的4-bit量化版）
ollama pull qwen2.5:7b
 
# 下载指定版本的模型
ollama pull llama3.1:8b-instruct-q4_K_M

# 查看本地模型
ollama list

# 删除模型
ollama rm qwen2.5:7b

# 查看正在运行的模型
ollama ps

# 停止正在运行的模型
ollama stop qwen2.5:7b

# 运行模型（如果模型未下载，会自动下载）
ollama run qwen2.5:7b
# 退出对话：输入`/bye`或按下 Ctrl+D


```


## 配置下载镜像源
配置环境变量
1. 变量名：`OLLAMA_REGISTRY`
2. 变量值：`https://mirror.ollama.ai`
