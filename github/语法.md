



# remote

```bash
# 添加远程仓库（最常见）
git remote add <远程名称> <仓库地址>

# 查看当前所有远程仓库
git remote -v

# 查看某个远程仓库的详细信息
git remote show origin

# 修改远程仓库地址
git remote set-url origin <新地址>

# 删除远程仓库
git remote remove origin

# 重命名远程仓库
git remote rename origin newname
```


给一个remote添加多个url
- 如果本来就有fetch和push，fetch不会变，push会覆盖，需要重新添加旧的
```bash
# 添加url
git remote set-url --add --push origin https://github.com/fire-dragon-boom/obsidian-knowledge-lib.git
git remote set-url --add --push origin git@gitee.com:ice_cold_fish/knowledge-base.git

# 删除push url
git remote set-url --delete --push origin https://github.com/fire-dragon-boom/obsidian-knowledge-lib.git
```
