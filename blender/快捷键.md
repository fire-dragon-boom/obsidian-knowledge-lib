# 物体模式

## 变换操作
应用变换：ctrl + a

## 操作面板
>操作完成后的数据面板->点击空白处消失->使用==F9==再次显示

## 移动
选中物体 -> G -> 鼠标移动
移动归零：alt + G
根据**轴**移动：z,x,y
根据**面**移动：shift + z,x,y

## 缩放
选中物体 -> S -> 鼠标移动
缩放归零：alt + S 


## 旋转
选中物体 -> R -> 鼠标移动
旋转归零：alt + R

## 镜像操作
选中物体 ->ctrl + M -> 轴向xyz

## 选择其他对象
ctrl + i -》选择剩余所有对象

## 隐藏其他对象
shift + h -》 隐藏其他对象
alt + h -》 显示其他对象
